Spatial-Mode Workflow: Visium Data with In Situ Connectivity Maps

2026-04-20

Overview

In spatially resolved transcriptomics, the physical positions of cells or spots are not incidental — they are biological information. Cells that are physically adjacent share a local microenvironment, exchange secreted molecules, and respond to the same spatial cues. Defining signaling neighborhoods by proximity is therefore more principled than random pairing.

NICHESv2’s spatial mode uses the coordinates in your data to construct a neighbor graph, then scores ligand–receptor-mediated (LRM) signaling along every edge of that graph. Two parameter paths are available:

  • kNN (k): each spot is connected to its k nearest neighbors by Euclidean distance. Simple and dataset-agnostic.
  • Radius (rad): each spot is connected to all spots within a fixed physical radius. More interpretable when the coordinate units have a known biological meaning (e.g. micrometres in Visium).

This vignette demonstrates the spatial-mode workflow using the stxBrain dataset: ~2,700 Visium spots from the mouse brain anterior section, with strong spatial tissue organisation that makes signaling patterns immediately interpretable.

Extracting spatial coordinates

Unlike Seurat objects with dimensionality reduction embeddings, Visium objects store spatial coordinates in the image slot rather than in cell metadata. extract_NICHESInputs_Seurat() does not automatically transfer them, so we do this manually before calling create_NICHESObject().

For VisiumV2 objects (Seurat ≥ 5), coordinates live in @images[[i]]@boundaries$centroids:

# Retrieve barcodes and coordinates from the VisiumV2 image slot
barcodes <- anterior1@images$anterior1@boundaries$centroids@cells
coords   <- anterior1@images$anterior1@boundaries$centroids@coords
rownames(coords) <- barcodes

# Safety check: all barcodes present in meta.data
all(barcodes %in% rownames(inputs.stx$meta.data))
#> [1] TRUE

sum(is.na(coords[rownames(inputs.stx$meta.data), "x"]))
#> [1] 0

# Join coordinates into meta.data by barcode name (safe, not positional)
inputs.stx$meta.data$x <- coords[rownames(inputs.stx$meta.data), "x"]
inputs.stx$meta.data$y <- coords[rownames(inputs.stx$meta.data), "y"]

head(inputs.stx$meta.data[, c("x", "y")], 3)

Step 2 — Choosing a neighborhood radius

NICHESv2 provides Explore_Radius_Neighborhood() to help you relate a physical radius value to the expected number of neighbors per spot, before you commit to building the full object. This is useful because the right radius depends on your tissue’s spot density and coordinate units, which vary across platforms and experiments.

The function samples a subset of spots, counts neighbors at each radius step, and returns a plot of mean neighbor count vs. radius:

coords.df <- data.frame(
  x = inputs.stx$meta.data$x,
  y = inputs.stx$meta.data$y
)

# Full range — get an overview first
Explore_Radius_Neighborhood(coords.df)

The full-range plot shows that large radii (>1000) produce hundreds of neighbors per spot — biologically implausible and computationally expensive. Zoom into the actionable range by setting r.max:

# Zoom into the actionable range
Explore_Radius_Neighborhood(coords.df, r.max = 800)

The staircase shape is a feature of the Visium hexagonal grid: spots are arranged in concentric hexagonal rings, so neighbor count increases in discrete jumps rather than smoothly. Reading the zoomed plot:

  • Radius ~200 → ~6 neighbors per spot (equivalent to the first hexagonal ring)
  • Radius ~400 → ~25–30 neighbors (two rings)
  • Radius ~600 → ~50–60 neighbors (three rings)

For a first analysis, 6 immediate neighbors is a natural starting point — it captures direct physical contacts without diluting the signal with distal spots. In this vignette we use k = 6 (kNN mode) for simplicity and reproducibility, which is equivalent to radius ~200 for this dataset:

Step 3 — Build the NICHESObject

niches.stx <- create_NICHESObject(
  count.mtx  = inputs.stx$count.mtx,
  meta.data  = inputs.stx$meta.data,
  LRM.db     = load_LRM_database("fantom5", species = "mouse"),
  mode       = "spatial",
  species    = "mouse",
  sample.col = NULL,
  k          = 6L,
  method     = "product",
  n.cores    = 4L,
  verbose    = TRUE
)

load_LRM_database("fantom5", species = "mouse") loads the bundled FANTOM5 ligand–receptor database for mouse — no internet connection required.

Step 5 — In situ connectivity map

CellToCell_InSitu_Single_LRM() maps the LRM score of every edge onto the tissue coordinate system, drawing each edge as a coloured line segment between sending and receiving spots.

Here we visualise Gnas|Adcy1 — Gnas (G protein alpha subunit) signalling to Adcy1 (adenylate cyclase 1). The resulting map reveals a striking cortical arc: high-scoring edges concentrate in the cortex, which wraps around subcortical structures along the lateral and inferior edges of the anterior section. This spatial pattern is consistent with the known high expression of adenylate cyclase in cortical neurons and reflects the power of spatial mode to localise signalling to anatomically coherent regions.

CellToCell_InSitu_Single_LRM(
  niches.obj    = niches.stx,
  LRM           = "Gnas|Adcy1",
  bg.alpha      = 0.3,
  bg.linewidth  = 0.2,
  sig.linewidth = 0.3,
  sig.alpha     = 0.7
)
