# Example NICHESv2 inputs (raw triple)

A small synthetic dataset providing the three raw inputs required to
construct a `NICHESObject`: a sparse expression matrix, a per-cell
metadata table with spatial coordinates and cell-type labels, and a
ligand–receptor database. Used by the example blocks of upstream
constructors such as
[`create_NICHESObject`](https://raredonlab.github.io/NICHESv2/reference/create_NICHESObject.md),
[`compute_CellToCell`](https://raredonlab.github.io/NICHESv2/reference/compute_CellToCell.md),
and the `create_Edgelist_*` family.

## Format

A named list with three components:

- `count.mtx`:

  50 x 80 `dgCMatrix` of UMI counts (genes x cells). Approximately 25%
  non-zero density.

- `meta.data`:

  80-row `data.frame` with columns `x`, `y` (spatial coordinates),
  `nCount_RNA` (per-cell library size), and `celltype` (one of
  `"TypeA"`, `"TypeB"`, `"TypeC"` forming three spatial clusters). Row
  names are cell barcodes.

- `LRM.db`:

  15-row `data.frame` with columns `ligand`, `receptor`, `pathway`.
  Three rows use underscore-delimited gene complexes (`"GeneA_GeneB"`)
  so example output exercises the complex-handling code path.

## Source

Synthetic data generated by `data-raw/build_NICHESv2_example.R`.
Deterministic (`set.seed(42)`).

## Details

The three components share barcodes and gene names so the standard
upstream pipeline runs end-to-end without any additional data wrangling.

## See also

[`NICHESv2_example`](https://raredonlab.github.io/NICHESv2/reference/NICHESv2_example.md)
for the prebuilt `NICHESObject` constructed from these inputs.
